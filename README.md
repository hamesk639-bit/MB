# Mohamed Bastawy — Engineering Portfolio

A responsive, static portfolio website built with HTML, CSS, and JavaScript. No backend, build tools, or paid services are required.

## Preview locally

From this directory run `python -m http.server 8000`, then visit `http://localhost:8000`.

## Publish for free with GitHub Pages

1. Create a public GitHub repository, e.g. `mohamed-bastawy-portfolio`.
2. Upload **the contents** of this directory to the repository root (including `assets/`).
3. Open repository **Settings → Pages → Build and deployment**.
4. Choose **Deploy from a branch**, `main`, `/ (root)`, and save.
5. Wait for GitHub Pages to provide a URL such as `https://YOUR-USERNAME.github.io/mohamed-bastawy-portfolio/`.
6. To update the website, edit or replace files in the repository and commit changes. Deployment will update automatically.

No custom domain or payment is required under current standard GitHub Pages public-repository hosting, subject to GitHub's published eligibility and usage policies. Free offerings can change.
